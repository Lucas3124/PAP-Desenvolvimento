# Knightborn 

Knightborn é um videojogo 2D de ação e aventura desenvolvido em Unity, com foco em progressão de personagem e combate em tempo real.  
O jogador controla um herói que enfrenta inimigos e desafios em diferentes fases, acumulando ouro como principal recurso do jogo.

## Principais Características
- Movimentação e combate em tempo real  
- Sistema de progressão baseado em ouro (ataque, defesa, vida)  
- Loja de armas (corpo a corpo e de fogo)  
- Gestão estratégica de recursos  

## Objetivo do Projeto
Desenvolver um jogo que combine diversão, progressão e estratégia, servindo também como plataforma de aprendizagem prática em:
- Programação orientada a objetos  
- Design de interfaces  
- Lógica de jogo  
- Utilização de GitHub para controlo de versão e colaboração
